
# Flutter Smartwatch Connection Sample Project




## About The Project

 This sample project demonstrates how to establish a connection between Flutter and various smartwatches, including Galaxy Watch, Apple Watch, Android Wear, Huawei Watch, and Galaxy Fit. The project utilizes the Flutter Method Channel to facilitate communication between the Flutter app and the smartwatch.

The project is currently in progress, it's in it's phase 1 with basic functionality implemented. The primary purpose of the project is to enable the smartwatch to send health data such as calories burned and heart rate to the Flutter app. This data can then be used for accurate workout prescription and monitoring.
